# Portfolio

A minimal Next.js portfolio starter using the App Router and TypeScript. The home page displays “Coming soon”.

## Run locally

Requires Node.js 20.9 or newer.

```bash
npm install
npm run dev
```

Open http://localhost:3000. Edit `app/page.tsx` to update the home page and `app/globals.css` to change its styling.

## Production

```bash
npm run build
npm start
```

Run `npm run typecheck` to check TypeScript types.
